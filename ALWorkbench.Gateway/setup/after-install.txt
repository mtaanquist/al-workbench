The AL Workbench Gateway is installed in:
    C:\Program Files\AL Workbench Gateway

If you upgraded an existing gateway, nothing is left to do: it keeps its
registration and its gateway.toml, and the service is running again.

What is left to do after a first install

1. Tell the gateway which service tiers it may manage.
   Copy gateway.example.toml to gateway.toml in that folder and edit it as
   administrator. Then open a command prompt with "Run as administrator" and run:
       cd "C:\Program Files\AL Workbench Gateway"
       ALWorkbench.Gateway check
   Fix anything it lists. The gateway picks up changes to gateway.toml by itself.

2. If you did not register during setup, register now from the same prompt,
   with a code from Administration > Gateways > Add gateway in AL Workbench:
       ALWorkbench.Gateway register --url https://your-al-workbench --code THE-CODE

3. In AL Workbench, approve the gateway under Administration > Gateways. Check
   that the fingerprint shown there matches the one the gateway printed when it
   registered. It is also in the newest log file (see below).

The service is called "AL Workbench Gateway". Its log files are in
C:\ProgramData\AL Workbench Gateway\logs.

To remove the gateway, uninstall it from Settings > Apps. That also deletes its
key and settings; then revoke it in AL Workbench.
